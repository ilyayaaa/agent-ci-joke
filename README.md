This program writes one joke to entry.txt: an agent asked to write a joke about agents generates 47 options, ranks them by confidence, picks the funniest, nobody laughs, so it marks the task completed and opens a pull request to fix the human's sense of humor. Run it with `python3 main.py` (output goes to MAKEFUN_OUTPUT_DIR, default /output) and verify it with `python3 check_entry.py`.
